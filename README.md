# كوميكس (عربي + إنجليزي) 🦸‍♂️📖

مستودع إضافات كوميكس لتطبيق **Harbor** يحتوي على أشهر مواقع الكوميكس العربية المترجمة ومواقع الكوميكس الإنجليزية والعالمية (DC, Marvel, Indie) المتوافقة 100% مع قارئ الشاشات وأجهزة التلفزيون (Tizen / WebOS / PC).

---

## 🌟 المصادر المتاحة والمفحوصة (Verified Sources)

### 🟢 المصادر العربية (Arabic Sources):
* **ArComixVerse (عربي):** ترجمات سلاسل دي سي ومارفل وبن 10 وباتمان وانفينسيبل (صفحات كاملة بدقة عالية).
* **Team X (عربي):** ترجمات حصرية لأحدث الفصول والأعداد.
* **Azora (عربي):** ترجمات شاملة وسيرفرات تصفح سريعة.

### 🔵 المصادر الإنجليزية (English Sources):
* **ComicK Comics (English):** قسم الكوميكس الغربي (Marvel, DC, Image, Dark Horse).
* **MangaPill Comics (English):** قارئ خفيف وسريع لأعداد الكوميكس والويب كوميكس.
* **Webtoons (English):** منصة الويب كوميكس الرسمية (قصص باتمان وريد هود الرسمية).

---

## 🚀 طريقة التثبيت في تطبيق Harbor:

1. افتح تطبيق **Harbor**.
2. توجّه إلى القائمة اليسرى ثم: **Plugins** ➔ **Plugin repositories**.
3. في خانة **Repository link**، الصق هذا الرابط:
```text
https://raw.githubusercontent.com/moahmmed597/Comics-for-harbor/main/repo.json
```
4. اضغط على زر **Add** (أو أيقونة التحديث 🔄 إذا كان المستودع مضافاً لديك مسبقاً).
5. اضغط على **Install** بجانب المصادر لتثبيتها وتشغيلها!
