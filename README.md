# كوميكس (عربي + إنجليزي) 🦸‍♂️📖

المستودع الأكبر والأشمل لإضافات الكوميكس والمانجا لتطبيق **Harbor**، يحتوي على **13 مصدراً معتمداً ومفحوصاً** (عربية وأجنبية) متوافقة 100% مع أجهزة التلفزيون (Samsung Tizen / LG WebOS / Android TV) والكمبيوتر.

---

## 🌟 المصادر المتاحة (13 مصدراً):

### 🟢 المصادر العربية (8 مواقع):
1. **ArComixVerse (عربي):** ترجمات سلاسل دي سي ومارفل وبن 10 وباتمان وانفينسيبل (صفحات كاملة بدقة عالية).
2. **مانجا العاشق (3asq):** الموقع الكلاسيكي الأضخم في الوطن العربي للأنمي والمانجا.
3. **Team X (عربي):** ترجمات حصرية وجودات فائقة.
4. **Azora (عربي):** مكتبة شاملة وسيرفرات تصفح سريعة.
5. **مانجا ليك (MangaLek):** المصدر العربي الأوسع انتشاراً.
6. **مانجا لينك (MangaLink):** متابعة أحدث الفصول يومياً.
7. **مانجا اون لاين (Manga Online):** تصفح خفيف وسريع.
8. **Manga Starz:** موقع ترجمات متميز.

### 🔵 المصادر الإنجليزية والعالمية (5 مواقع):
9. **ComicK Fanmade (English):** قسم الكوميكس الغربي (Marvel, DC, Image, Dark Horse).
10. **ComicK Unoriginal (English):** قاعدة بيانات الكوميكس والمانهوا المترجمة.
11. **MangaPill Comics (English):** قارئ خفيف وسريع لأعداد الكوميكس.
12. **Manganato (English):** أحد أكبر المواقع العالمية.
13. **Webtoons.com (English):** منصة الويب كوميكس الرسمية (قصص باتمان وريد هود).

---

## 🚀 طريقة التثبيت في تطبيق Harbor:

1. افتح تطبيق **Harbor**.
2. توجّه إلى القائمة اليسرى ثم: **Plugins** ➔ **Plugin repositories**.
3. في خانة **Repository link**، الصق هذا الرابط:
```text
https://raw.githubusercontent.com/moahmmed597/Comics-for-harbor/main/repo.json
```
4. اضغط على زر **Add** (أو زر التحديث 🔄 إذا كان المستودع مضافاً لديك مسبقاً).
5. اضغط على **Install** بجانب أي موقع تريده!
