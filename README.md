# مستودع الكوميكس لتطبيق هاربورد (Comics for Harbor)

مستودع مخصص حصرياً للكوميكس (عربي وإنجليزي) مصمم ليعمل 100% على تطبيق Harbor على التلفزيون (Samsung Tizen) والكمبيوتر.

## رابط الإضافة في تطبيق Harbor:
```text
https://raw.githubusercontent.com/moahmmed597/Comics-for-harbor/main/repo.json
```

## المصادر المشمولة والمفحوصة (100% شغالة):
1. **ArComixVerse (عربي)**: ترجمات أعداد كوميكس DC، Marvel، Invincible، Ben 10، وغيرها من الكوميكس الغربي باللغة العربية.
2. **ComicK Comics (English)**: مكتبة الكوميكس الغربي الكاملة (Marvel, DC Comics, Image, Dark Horse, Indie) باللغة الإنجليزية مع تصفح وقراءة الصفحات مباشرة.
3. **Webtoons (English)**: قصص ومسلسلات الكوميكس المصورة والويب كوميكس الشهيرة باللغة الإنجليزية.

جميع الإضافات مفحوصة وتدعم:
- تصفح الأحدث والشائع (Popular)
- عرض قائمة الأعداد والفصول (Chapters)
- استخراج وقراءة كامل الصفحات عالية الدقة (Pages)
