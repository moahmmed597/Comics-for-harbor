# مستودع الكوميكس لتطبيق هاربورد (Comics for Harbor)

مستودع مخصص حصرياً للكوميكس (عربي وإنجليزي) مصمم ومضبوط ليعمل 100% على تطبيق Harbor على التلفزيون (Samsung Tizen) والكمبيوتر.

## رابط الإضافة في تطبيق Harbor:
```text
https://raw.githubusercontent.com/moahmmed597/Comics-for-harbor/main/repo.json
```

## مصادر الكوميكس الستة (مفحوصة وشغالة 100%):

### المصادر العربية:
1. **ArComixVerse (عربي)**: ترجمات كاملة لأعداد كوميكس DC، Marvel، Invincible، Ben 10 باللغة العربية مع تصفح كامل الصفحات عالية الدقة.
2. **عرب كوميكس - ArabComics (عربي)**: أشهر وأضخم أرشيف ومجتمع كوميكس عربي، مضبوط ليعمل مباشرة بدون شاشة سوداء أو أخطاء.

### المصادر الإنجليزية والعالمية:
3. **ComicK Comics (English)**: مكتبة الكوميكس الغربي الكاملة (Marvel, DC, Image, Dark Horse, Indie) باللغة الإنجليزية.
4. **Webtoons (English)**: أكبر منصة عالمية للويب كوميكس وروايات الأبطال الخارقين المصورة.
5. **GetComics (English)**: المصدر العالمي لإصدارات وأعداد الكوميكس الأسبوعية، مضبوط لعرض وتصفح الإصدارات مباشرة.
6. **GlobalComix (English)**: المنصة العالمية الشهيرة، مضبوطة للعمل وتصفح السلاسل والإصدارات والمعاينات.

جميع الإضافات مفحوصة ومجربة في بيئة Harbor وتجتاز اختبارات التشغيل والقوائم والفصول والصفحات.
